\section{Version History}
\label{sec:VersionHistory}

Version information is automatically tracked using git tags. The versioning scheme follows semantic versioning (MAJOR.MINOR.PATCH).

\begin{itemize}
    \item \textbf{MAJOR}: Significant changes to architecture or breaking changes
    \item \textbf{MINOR}: New features or non-breaking changes
    \item \textbf{PATCH}: Bug fixes and hotfixes
\end{itemize}
